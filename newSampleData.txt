4.$lookup, $unwind

1. get customer details for each order

syntax:
-------
{
   $lookup:
     {
       from: <collection to join>,
       localField: <field from the input documents>,
       foreignField: <field from the documents of the "from" collection>,
       as: <output array field>
     }
}


db.orders.aggregate([
    {
        $lookup: {
            from: "customers",
            localField: "customerId",
            foreignField: "customerId",
            as: "customersDetails"
        }
    },

    {
        $unwind: "$customersDetails"
    }
])


2. Display each order with its cutomer name and membership

db.orders.aggregate([
    {
        $lookup: {
            from: "customers",
            localField: "customerId",
            foreignField: "customerId",
            as: "customersDetails"
        }
    },

    {
        $unwind: "$customersDetails"
    },

    {
        $project:{
            _id:0,
            orderId:1,
            product:1,
            amount:1,
            customeName:"$customersDetails.name",
            membership:"$customersDetails.membership"
        }
    }
])

4. Find all orders belonging to gold members

db.orders.aggregate([
  
    {
        $lookup: {
            from: "customers",
            localField: "customerId",
            foreignField: "customerId",
            as: "customersDetails"
        }
    },

    {
        $unwind: "$customersDetails"
    },

      {

            orderId:1,

            amount:1,
            customeName:"$customersDetails.name",
            membership:"$customersDetails.membership"

3. get delivered and Pending order counts in one query

output: 

{
    deliveredOrders:[{count:5}],
    PendingOrders: [{count:2}]
}

db.orders.aggregate([
    {
        $facet : {
            deliveredOrders:[
                {
                    $match: {
                        status: "Delivered"
                    }, 
                },
                 {
                        $count: "count"
                }
            ],
            PendingOrders:[
                 {
                    $match: {
                        status: "Pending"
                    },
                     
                },
                {
                        $count: "count"
                    }
            ]
        }
    }
])
