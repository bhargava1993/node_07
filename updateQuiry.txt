---------------------------------------------

updateOperation:
$set
$inc - increment
$unset - remove a field
$min
$max
$mul
$rename
$currentDate


updateOne() — when you want an update result such as matched and modified counts.
updateMany()- when you want an update multiple documents result such as matched and modified counts.
findOneAndUpdate() — when you want the document returned as part of the update operation.


upsert: true
If the document exists, update it. If it doesn't exist, insert a new document.

-----------------------------------------------------------------------------------------


1. updateOne() - update only one document

syntax:
db.students.updateOne(
  {filterCondition},
  {updateOperation: { filed:value }}
)

Q1. A student 102 changes their department from ECE to CSE 

db.students.findOne({ studentId: 102})

db.students.updateOne(
  { studentId: 102},
  {$set: { department:"CSE" }}
)

Update multiple files in the document
---------------------------------------
db.students.updateOne(
  { studentId: 103},
  {$set: { department:"IT", year:3, active:false,marks:70 }}
)

update a nested object filed:
-------------------------------

db.students.updateOne(
  { studentId: 103},
  {$set: { "address.city": "Hyderabad" }}
)

------------------------------------------------------------------

UpdateMany() - update multiple documents
-----------------------------------------


Q1. update every cse student fees

db.students.updateMany(
 
  {department:"CSE"},
  {$set: {fees: 48000}}
)

increment marks for every active student:
--------------------------------------------

db.students.updateMany(
 
  {active: true},
  {$inc: {marks: 5}}
)

db.students.updateMany(
 
  {active: true},
  {$inc: {fees: 1000}}
)

db.students.updateMany(
 
  {year: 4},
  {$set: {year:5}}
)

db.students.updateMany(
  {"address.city": "Hyderabad"},
  {$set: { "address.state":"Telangana"}}
)


findOneAndUpdate():   update and return a document
--------------------------------------------------

db.students.findOneAndUpdate(
  {filterCondition},
  {updateOperation: { filed:value }},
  {returnDocument: "after"}
)

ex:

db.students.findOneAndUpdate(
  {studentId:101},
  {$set: { department : "IT" }},
  {returnDocument: "after"}
)

db.students.findOneAndUpdate(
  {studentId:101},
  {$set: { department : "CSE" }},
 {returnDocument: "before"}
)

db.students.findOneAndUpdate(
  {studentId:103},
  {$inc: { marks : 10 }},
  {returnDocument: "after"}
)


------------------------------------------------------

upsert : true --> update or insert

if document is exists, update it, 
if document doesn't exists, insert new documents

db.students.updateOne(
  {studentId:101},
  {$set: {department: "IT" }},
  {upsert: true}
)

-----------------------------

$unset - remove a filed

db.students.updateOne(
  {studentId:101},
  {$unset: {department: "" }},
  {upsert: true}
)

db.students.findOneAndUpdate(
  {studentId:101},
  {$unset: {year: "" }},
  {returnDocument: "after"}
)

$min
$max
$mul
$rename
$currentDate

db.students.findOneAndUpdate(
  {studentId:101},
  {$min: {marks: 70 }},
  {returnDocument: "after"}
)

db.students.findOneAndUpdate(
  {studentId:101},
  {$max: {marks: 80 }},
  {returnDocument: "after"}
)

db.students.findOneAndUpdate(
  {studentId:101},
  {$mul: {fees: 1.1 }},
  {returnDocument: "after"}
)

db.students.findOneAndUpdate(
  {studentId:101},
  {$rename: {marks: "totalMarks"}},
  {returnDocument: "after"}
)

db.students.findOneAndUpdate(
  {studentId:101},
  {$currentDate: {lastUpdated: true}},
  {returnDocument: "after"}
)
